# Storyboard · Gestión de sedes V1

**Módulo:** Clientes → Sedes
**Video ID:** `clientes-sedes-v1`
**Salida:** `clientes-gestion-sedes-v1.mp4`

## Objetivo

Mostrar cómo crear una Sede dentro de un cliente Negocio, explicar los accesos rápidos de contacto y dejar clara la configuración de vehículos y certificados.

## Reglas funcionales

- Las Sedes pertenecen a clientes de tipo **Negocio**.
- El contacto principal registra nombre, celular y correo.
- El celular ofrece acceso rápido a WhatsApp.
- El correo ofrece acceso rápido para redactar un mensaje.
- Se pueden registrar correos adicionales e incluir los correos generales del cliente.
- La configuración operativa incluye valor, periodicidad, duración y visita de refuerzo.
- Si la Sede maneja vehículos, puede definirse si esos vehículos generan certificado y su vigencia en meses.
- Los vehículos se crearán posteriormente dentro de la Sede; este video no inventa una pantalla que todavía no existe.
- El plano es un archivo privado opcional.

## Datos de demostración

Se utilizan únicamente nombres, teléfonos y correos sintéticos preparados para el video.
