# Storyboard · Gestión de criterios MIP V1

**Módulo:** Configuración → Catálogos MIP → Criterios  
**Salida:** `mip-gestion-criterios-v1.mp4`  
**Objetivo:** al terminar el video, el usuario podrá crear un criterio, definir su alcance, consultar y editar el registro, desactivarlo, reactivarlo y eliminarlo cuando no tenga referencias ni historial.

## Reglas funcionales que debe enseñar

- Un criterio define qué evalúa el Técnico dentro de cada Área durante un Servicio Principal.
- Cada criterio conserva nombre, estado y alcance.
- Alcance:
  - **Todas las áreas**.
  - **Solo exterior / perímetro**.
- Los estados C, CP, NC y NA son valores fijos del sistema y no se administran aquí.
- Desactivar conserva histórico; eliminar solo corresponde a registros sin referencias ni historial.
- Los cambios del catálogo afectan servicios que todavía no han iniciado; el histórico conserva snapshots.

## Datos de demostración

- Existentes: Instalación de barreras físicas; Disposición adecuada de residuos sólidos y líquidos; Mantenimiento higiénico; Mantenimiento locativo interno y externo; Mantenimiento de zonas verdes.
- Nuevo: Criterio de demostración.
- Editado: Criterio demostración perímetro.
- Alcance: Solo exterior / perímetro.

## Escenas

1. Portada.
2. Configuración → Catálogos MIP.
3. Abrir Criterios.
4. Explicar listado.
5. Buscador.
6. Nuevo criterio.
7. Nombre.
8. Explicar opciones de aplicación.
9. Todas las áreas.
10. Solo exterior / perímetro.
11. Aclarar estados C, CP, NC y NA.
12. Seleccionar exterior y crear.
13. Mostrar creado.
14. Abrir detalle.
15. Mostrar alcance.
16. Editar.
17. Guardar nombre actualizado.
18. Señalar acciones.
19. Desactivar.
20. Confirmar.
21. Mostrar Inactivos.
22. Reactivar.
23. Mostrar Activos.
24. Abrir eliminación y explicar restricción.
25. Confirmar.
26. Mostrar resultado.
27. Cierre.

## Sincronización

- El selector de aplicación permanece visible durante toda la explicación del alcance.
- La selección Solo exterior / perímetro ocurre dentro del segmento de creación.
- El detalle permanece abierto durante su explicación.
- Las confirmaciones permanecen abiertas hasta el segmento que confirma la acción.
- Voz y subtítulos usan exactamente el mismo texto.
